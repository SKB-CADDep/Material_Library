================================================================================
  Material Library — инструкция для пользователя (Windows)
================================================================================

КАК ЗАПУСТИТЬ
-------------
1. Откройте папку программы (локальный диск или \\fileserver\...).
2. Дважды щёлкните:

      Запуск Material Library.bat

   Запуск идёт через встроенный Python.
3. Откроется браузер: http://127.0.0.1:8000
4. Не закрывайте чёрное окно сервера, пока работаете.



КАК ОСТАНОВИТЬ
--------------
Дважды щёлкните:

      Остановить Material Library.bat


ЧАСТЫЕ СООБЩЕНИЯ
----------------

«Не найден Python для запуска» / нет runtime/python
  → Дистрибутив неполный. Запросите у разработчиков полный архив.

«Не найден собранный интерфейс (frontend/dist)»
  → Дистрибутив неполный. Запросите полный архив.

«Порт 8000 занят»
  → Запустите «Остановить Material Library.bat» и попробуйте снова.

Network Error / пустая страница после запуска с файлсервера
  → Остановите программу и запустите снова с обновлёнными scripts\.
  → Не закрывайте окно Python/uvicorn.
  → В окне запуска должна быть строка MATERIALS_DIR=\\fileserver\...
    (не Z:\...).


ГДЕ ЛЕЖАТ ДАННЫЕ
----------------
Файлы материалов и source.json — в подпапке «data».
Программа открывает её автоматически.
