================================================================================
  Material Library — инструкция для пользователя (Windows)
================================================================================

КАК ЗАПУСТИТЬ
-------------
1. Откройте папку программы.
2. Для обычного запуска дважды щёлкните:

      Start Material Library.vbs

   Окна не будет. Через пару секунд откроется браузер:
   http://127.0.0.1:8000
3. Если запуск не удался, откроется чёрное окно с текстом ошибки.
4. Закрытие вкладки браузера программу не останавливает.
   Повторный запуск снова открывает сайт.

Файл «Manual start Material Library.bat» — ручной запуск. Он оставляет
чёрное окно открытым на всё время работы и нужен, только если хотите
видеть журнал сервера. Для обычной работы его не запускайте.



КАК ОСТАНОВИТЬ
--------------
Дважды щёлкните:

      Stop Material Library.bat


ЧАСТЫЕ СООБЩЕНИЯ
----------------

«Не найден Python для запуска» / нет runtime/python
  → Дистрибутив неполный. Запросите у разработчиков полный архив.

«Не найден собранный интерфейс (frontend/dist)»
  → Дистрибутив неполный. Запросите полный архив.

«Порт 8000 занят»
  → Запустите «Stop Material Library.bat» и попробуйте снова.

ГДЕ ЛЕЖАТ ДАННЫЕ
----------------
Файлы материалов и source.json — в подпапке «data».
Программа открывает её автоматически.
